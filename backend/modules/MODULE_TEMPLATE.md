# 模块 README 模板

复制本模板时，请把标题和内容替换为真实模块说明。

## 模块职责

说明这个模块负责什么业务。

示例：

- 管理某类 API。
- 封装某类业务逻辑。
- 维护某类数据访问边界。

## 主要文件

- `api.py`：FastAPI router。
- `service.py`：业务逻辑。
- `schemas.py`：请求和响应模型。
- `README.md`：模块说明。

按实际情况删除不存在的文件说明。

## 依赖关系

说明本模块可以依赖哪些模块或服务。

如果依赖人物数据，优先通过 `modules.characters` 读取。

## 数据边界

说明本模块会读取或写入哪些数据。

如果模块不写文件或数据库，也应明确说明。

## 注意事项

- 不要静默吞掉关键错误。
- 不要绕过已有 service。
- 不要在模块外复制路径拼接逻辑。
- 不要把临时实现写成长期接口。
