# 桌面端前端设计

## 定位

本项目现在只有一个前端：`frontend/desktop/`。旧 `frontend/simple_web` 已删除，不再保留旧 HTML + app.js 网页前端，也不再通过 `/app/` 使用主界面。

后端仍是 FastAPI，默认地址：

```text
http://127.0.0.1:8000
```

后端接口文档通过：

```text
http://127.0.0.1:8000/docs
```

## 技术栈

- Electron：Windows 桌面端窗口。
- React + TypeScript + Vite：前端工程。
- Tailwind CSS + Radix UI：界面样式和弹窗等基础交互。
- TipTap：后续日记 / 计划编辑体验。
- react-markdown：日记 Markdown 预览。
- Zustand：轻量前端状态。
- TanStack Query：后端请求与缓存。
- lucide-react：图标。

## 主功能

主导航只包含：

```text
聊天
日记
日程
设置
```

角色和记忆不是一级入口，而是嵌入到底层的能力。角色管理和记忆管理放在设置或高级区域。

## 布局

桌面端采用宽屏优先三栏布局：

```text
左侧：主导航
中间：主功能区
右侧：上下文 / 附件 / 状态 / 设置面板
```

整体风格借鉴 floral-notepaper 的纸张感、便签感、柔和阴影和低饱和配色；日程页结构借鉴 Mnemo 的今日任务、月历和计划卡片组织方式。

## 页面

### 聊天

聊天页调用现有 `/chat/text`。普通聊天不携带日记；只有用户主动在日记页选择“让角色读这篇日记”时，才发送 `diary_entry_id`。

### 日记

日记页调用现有 `/diary/entries` 和 `/diary/entries/{entry_id}/images`。图片使用后端返回的 public URL 显示，不转 base64。

### 日程

当前只提供高质量空状态、今日任务卡片、月历骨架和任务状态样式。后端日程接口未实现时不写假数据、不 mock 任务。

### 设置

设置页调用 `/auth/me` 和 `/auth/me/avatar`，支持修改显示 ID / 用户名、上传头像、保存后端地址和查看连接状态。后端地址默认 `http://127.0.0.1:8000`，可改为 `http://127.0.0.1:8010` 或 `http://127.0.0.1:18000`。
